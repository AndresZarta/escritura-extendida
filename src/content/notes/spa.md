SPA (Single Page Application) es un patrón de desarrollo web en el que toda la navegación y actualización de contenido ocurre dentro de una única página HTML. En lugar de recargar diferentes páginas completas al navegar, el sitio utiliza JavaScript para modificar el [[DOM|arbol_del_dom]] de una única página y mostrar nuevas vistas dinámicamente. Esto permite experiencias más fluidas, pero suele implicar mayor complejidad y una separación distinta entre documento y aplicación.
