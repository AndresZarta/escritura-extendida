Un sitio web dinámico genera su contenido en el momento en que el usuario lo solicita. Usa lenguajes de servidor como PHP o Node.js, y bases de datos como MySQL o PostgreSQL. Este enfoque permite crear experiencias interactivas: **comentarios**, **búsquedas**, **paneles de usuario**, **formularios complejos**, etc. Pero también introduce complejidad: actualizaciones constantes, plugins potencialmente vulnerables, variaciones de rendimiento, y la necesidad de administrar infraestructura o pagar por quien la administre.
