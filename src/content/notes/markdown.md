# markdown(.md)

Markdown es un lenguaje de marcado ligero diseñado para facilitar la escritura y lectura de texto que puede convertirse fácilmente en HTML. Su sintaxis es simple y legible, permitiendo estructurar documentos con títulos, listas, enlaces, imágenes, citas y código, sin la complejidad de etiquetas HTML.

## Características principales
- Sintaxis sencilla y minimalista.
- Permite escribir contenido estructurado (títulos, listas, tablas, etc.).
- Fácil de convertir a HTML y otros formatos.
- Muy utilizado en documentación, blogs, README de proyectos y notas.

```md
# Título principal

Este es un párrafo en Markdown.

- Lista
- De
- Elementos

Negrita: **texto en negrita**
Itálica: *texto en cursiva* 
`código en línea`

[Enlace](https://commonmark.org)
```

Markdown es ideal para quienes desean centrarse en el contenido sin distraerse con el formato.
