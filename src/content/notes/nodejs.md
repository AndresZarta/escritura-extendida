**Node.js** es un entorno de ejecución para JavaScript construido sobre el motor V8 de Chrome, que permite ejecutar código JavaScript fuera del navegador, principalmente en el servidor. Su arquitectura orientada a eventos y su modelo asíncrono lo hacen ideal para aplicaciones escalables y de alto rendimiento.

En el caso de [[sitios_web_estaticos|sitios web estáticos]], Node.js se utiliza comúnmente durante el proceso de construcción (**build**) para generar los archivos HTML, CSS y JavaScript finales que serán servidos al usuario. Herramientas como [[astro|Astro]], [[nextjs|Next.js]] o [[gatsby|Gatsby]] aprovechan Node.js para compilar componentes, optimizar recursos y preparar el sitio para su despliegue.
