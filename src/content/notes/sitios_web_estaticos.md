Los sitios web estáticos se caracterizan por servir contenido previamente generado. Cada página existe como un archivo HTML, acompañado de hojas de estilo (CSS) y scripts de comportamiento (JavaScript). Esto los hace extremadamente **rápidos**, **baratos** o incluso **gratuitos**, **seguros** y **fáciles de desplegar**. No requieren bases de datos ni procesamiento en el servidor: el navegador recibe el contenido ya prerenderizado. Son ideales para blogs, portafolios o documentación técnica donde el contenido no cambia con frecuencia o puede ser actualizado a través de un flujo de despliegue controlado.
